# 集成测试说明

## 测试场景：两端 WebRTC 通话

### 前置条件
- 服务器已启动（`python signaling_server.py`）
- 使用支持 WebRTC 的浏览器（Chrome / Firefox / Edge）

---

### 场景 1：WS 连接 SDP 交换

**步骤**：
1. 打开两个浏览器标签页，均访问 `http://localhost:8765/`
2. 两个标签页填写相同房间 ID（如 `room-001`），服务器地址填 `ws://localhost:8765`
3. 标签页 A 点击「连接服务器」→ 状态显示 `已加入房间，角色: caller`
4. 标签页 B 点击「连接服务器」→ 双方状态显示 `对方已加入房间`
5. 标签页 A（caller）点击「开始通话」
6. 观察状态栏：`已创建 SDP Offer` → `已创建 SDP Answer` → `ICE 连接状态: connected`

**预期结果**：
- 双方视频区域均显示画面
- 状态栏显示 `WebRTC 连接已建立`

---

### 场景 2：WSS 加密连接

**前置**：先访问 `https://localhost:8766` 信任自签名证书

**步骤**：
1. 将服务器地址改为 `wss://localhost:8766`
2. 重复场景 1 的步骤

**预期结果**：与场景 1 相同，连接通过加密通道建立

---

### 场景 3：对方断开处理

**步骤**：
1. 建立通话后，关闭其中一个标签页
2. 观察另一个标签页的状态栏

**预期结果**：状态栏显示 `对方已离开房间`，通话自动结束

---

### 场景 4：房间满员拒绝

**步骤**：
1. 两个标签页已加入同一房间
2. 第三个标签页尝试加入同一房间

**预期结果**：第三个标签页状态栏显示 `服务器错误: 房间已满（最多 2 人）`
